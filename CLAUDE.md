# CLAUDE.md — соглашения проекта CrankyPanky

Информационно-образовательный ресурс для семей с СД1 (ребёнок + родитель).
Цель — актуальная, применимая в жизни информация. Не источник персональных
медицинских назначений.

## Архитектура (зафиксировано)

- Ядро — база знаний. Каналы (YouTube/TG/IG/Telegraph/аудио) — дистрибуция,
  производная от ядра; в дереве знаний их нет (см. `channels/`).
- Сайт собирается MkDocs Material из `build/` (инжект фронтматтера).
- Лицензия CC BY-SA 4.0.

## Два типа карточек

- `knowledge` — факт/евергрин (правило 15, пределы Libre).
- `decision` — фасетный выбор (выбор помпы). Сужает + источники, **не вердикт**.
  Всегда `freshness.class: volatile`.

## Метаданные

Каноничны в `*.meta.yml` рядом с `*.md` (раздельно — осознанное решение).
Фронтматтер для MkDocs инжектится из них, руками во `.md` не дублируется.

## Свежесть

- `class`: evergreen | slow | volatile — политика, не дата.
- Класс ограничен типом/severity; цикл можно только **укоротить**, не удлинить.
- `last_reviewed` ставит человек. `next_review`/`state` вычисляет
  `tools/freshness.py`, руками не пишутся.
- `watch_sources` — событийная дорожка (протухание по событию, не по часам).
- evergreen ≠ «не смотреть никогда»: страховочный горизонт/событийная привязка.
- Острая просроченная карточка показывается с **баннером** (не прячется,
  не деградирует). Громкость баннера — функция данных (`banner_severity`).

## Доверие (блок 0) — гейт

- ИИ-рецензент (`scripts/review.sh`) — предфильтр, НЕ финальный допуск.
- `severity: acute` + `publish_state: published` ⇒ обязателен `signoff: signed`
  (человек с медобразованием) и непустой `clinical_refs`. Иначе
  `tools/validate_metadata.py` падает → CI падает.
- На старте острое идёт как `draft_verifying` (решение «помечаем»).

## Имена

`content/NN_modul/NN-MM_slug.md` + `NN-MM_slug.meta.yml`.
Заголовок модуля — в `_module.md`, в карточках начинается с `##`.

## Перекрёстные отсылки

В `content/` пишутся простым текстом: `→ См. «Заголовок карточки»`,
`→ См. «A» и «B»`, `→ См. блок «Психология и устойчивость»`. Заголовок — `title`
из `.meta.yml` или заголовок `_module.md` без номера. Ссылками их делает
`tools/crossrefs.py` при сборке `build/`; руками markdown-ссылки не ставятся.
Неразрешённая отсылка — WARN в `validate_metadata.py`, CI не валит (решение).
