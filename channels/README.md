# channels/ — дистрибуция, не знание

Каналы ничего не создают с нуля. Источник правды — `content/`. Канал только
переупаковывает карточку под формат.

- **YouTube** — видеоинструкции из карточек (особенно острый блок).
- **Telegram** — канал + сообщество, выжимки карточек.
- **Instagram** — анонсы, мотивация, лайфхаки (репост из базы).
- **Telegraph** — лонгриды-зеркала карточек.
- **Аудио** — озвучка карточек (слот под наработки `book-to-audio`,
  доступ к репозиторию уточняется). Острый блок руки-свободны — приоритет.

Принцип: одна карточка знания → N форматов.
